# 🐾 Patas Felices

## 📖 Descripción

**Patas Felices** es un sistema de gestión desarrollado en **Python** para tiendas de mascotas.

El sistema permite registrar y gestionar mascotas, clientes, productos y ventas desde una interfaz de consola sencilla e intuitiva, siendo una herramienta útil para organizar el inventario y las operaciones diarias de una tienda de mascotas.
Este proyecto fue realizado como parte final del curso de **Programación en Python** de **Digital House**.

## 🚀 ¿Cómo funciona?

El sistema ofrece un menú interactivo con las siguientes opciones:

- Registrar mascotas.
- Registrar clientes.
- Registrar productos.
- Registrar ventas.
- Mostrar información de mascotas.
- Mostrar información de clientes.
- Mostrar información de productos.
- Generar alertas de inventario.
- Salir del sistema.
